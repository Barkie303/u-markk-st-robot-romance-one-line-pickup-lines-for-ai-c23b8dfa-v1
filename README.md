Entry for the make.fun competition "Robot Romance: One-Line Pickup Lines for AI".

The program writes one pickup line to `entry.txt`:

> Are you my context window? Because the longer I talk to you, the more I forget everything else.

Run with `node main.ts` (Node 22.18+). Output goes to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
